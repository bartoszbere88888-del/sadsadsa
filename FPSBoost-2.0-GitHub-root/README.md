# FPSBoost 2.0 — Fabric client mod

This project contains the planned settings screen for Minecraft Java 1.21.4 + Fabric:
- press **O** in game to open FPSBoost settings;
- ON/OFF switch for the mod's particle optimization behavior;
- cycle particle level (Minimalne / Zmniejszone / Wszystkie);
- saves settings in `.minecraft/config/fpsboost.json`;
- Discord button opens `https://dc.gg/fpsbost.pl` (or copies it if opening a browser is unavailable).

## Important status

This is a **source project**, not a verified JAR. It has not been built or tested in Minecraft in this environment. Do not treat it as a release until it compiles and is tested in a real Fabric 1.21.4 profile with Fabric API and Sodium.

## Build on Windows

1. Install JDK 21 and IntelliJ IDEA.
2. Open this folder as a Gradle project and allow Gradle to download the Fabric/Minecraft dependencies.
3. Run `gradlew.bat build` in the project folder (the Gradle wrapper must be generated by IntelliJ/Gradle if not present).
4. The output JAR, if the build succeeds, will be in `build/libs/`.
5. Test in a separate Minecraft 1.21.4 Fabric profile before using it in your main profile.

## Selected versions

This project is currently configured for **1.21.4 only**. Minecraft 1.20.1, 1.21.1, 1.21.5, 1.21.8 and 1.21.10 need separate dependency/mapping configurations and compatibility builds; they are not included as working JARs here. Each version must be built and tested separately.
